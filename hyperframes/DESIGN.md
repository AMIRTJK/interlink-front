# DESIGN.md — бренд-референс для HyperFrames-композиций INTERLINK

Этот файл — единственный источник правды по палитре, типографике и тональности для всех
композиций в `hyperframes/`. Значения синхронизированы с рантаймом приложения.

## Назначение композиций

Композиции здесь — **дизайн-стенд**, а не продакшн-ассет. В приложении анимация входа
живёт как React/`framer-motion` рантайм в `src/widgets/AuthWelcome/`. Композиция нужна,
чтобы покадрово вылизать тайминг и easing в `npx hyperframes preview`, а затем перенести
итоговую таблицу таймингов в React-компонент. См. раздел 10 в
`plan/2026-07-25-welcome-animation-hyperframes-prompt.md`.

## Палитра

База всегда тёмная — экран приветствия стыкуется со страницей логина (`#020617`).

| Токен | Значение | Откуда |
| --- | --- | --- |
| `--bg` | `#020617` | `pages/Auth/Auth.tsx`, `bg-[#020617]` |
| `--ink` | `#ffffff` | текст на тёмном |
| `--paper` | `rgba(255,255,255,0.08)` | «бумага» письма (glassmorphism проекта) |
| `--paper-border` | `rgba(255,255,255,0.15)` | границы карточек |

Акцент берётся из активной темы пользователя. В рантайме это
`THEMES[currentTheme].gradient` / `.dark` из `src/widgets/layout/ui/designSettings.ts`.
В композиции подставляются два хекса `--accent` / `--accent-2`:

| Тема | `--accent` | `--accent-2` |
| --- | --- | --- |
| `emerald` (по умолчанию) | `#10b981` | `#14b8a6` |
| `blue` | `#3b82f6` | `#6366f1` |
| `ocean` | `#22d3ee` | `#4f46e5` |
| `purple` | `#a855f7` | `#3b82f6` |
| `galaxy` | `#7c3aed` | `#3b82f6` |
| `sunset` | `#f97316` | `#a855f7` |

Проверять композицию нужно минимум на `emerald` и `galaxy` — это крайние случаи по
светлоте.

## Типографика

- **Логотип** — `INFRATECH`, шрифт **Orbitron** (`assets/fonts/Orbitron-Variable.woff2`,
  локальная копия из `public/fonts`), `font-weight: 500`, `letter-spacing: 0.25em`.
  Внешние CDN шрифтов запрещены. Кириллицы в Orbitron нет — русский текст рисуется
  системным sans, ровно как в приложении.
- **Остальной текст** — `"Segoe UI", Inter, system-ui, sans-serif` (в приложении Inter
  подключён через `@fontsource`).
- Кегли для 1920×1080: имя пользователя 104 px, штамп «ЭЦП» 64 px, логотип 46 px,
  подписи/лейблы 20–24 px. Ниже 20 px не опускаться.

## Тональность

Корпоративная, «безопасно и технологично». Предметная область — электронная
корреспонденция: входящие/исходящие письма, визы, резолюции, ЭЦП, кадры, задачи.
Никакой игровой пластики: без пружинных перелётов, без ярких вспышек на весь кадр,
без случайности. Движение — уверенное, с `power2`/`power3`, финал всегда спокойный.

## Технические правила

- 1920×1080, 30 fps, длительность 5–8 с.
- Один `gsap.timeline({ paused: true })` на `window.__timelines["main"]`.
- Никаких `Math.random()`, `Date.now()`, `repeat: -1`, `requestAnimationFrame`.
- Окна клипов тилятся без зазоров; полноэкранная заливка — на full-bleed **дочернем**
  элементе, не на корне.
- `npx hyperframes check` должен проходить без ошибок.

### Известные допустимые предупреждения `check`

- `rotation_pivot_drift` на листах письма — листы одновременно летят и вращаются,
  поэтому центр их bbox по определению смещается. `transform-origin: 50% 50%` задан явно;
  предупреждение ложное для такой пластики.
- Контраст текста штампа (`2.44:1` при норме `3:1`, t≈3.5 с) — белый «ЭЦП» лежит на
  полупрозрачной «бумаге» поверх акцентного глоу. Это транзиентный акцент движения,
  а не статичный UI-текст, и норма WCAG к нему не применима. Проверено: снижение
  прозрачности вспышки на цифру не влияет — источник просадки именно стопка бумаги.
  Ядро вспышки всё равно сделано прозрачным (`radial-gradient` донат), чтобы вспышка
  никогда не перекрывала текст.
