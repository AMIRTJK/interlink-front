# Оформления чата: переключение тем

Дата: 2026-08-20. Этап 1 — два оформления и переключатель.

## Проблема

Модуль «Чат» готов, API подключены. Нужно дать пользователю выбор оформления:
текущий дизайн и новый (светлые карточки, пастельные пузыри, другое
расположение элементов). Требования:

- обе темы работают и в разделе «Чат» (`AppRoutes.CHAT`), и во всплывающем окне;
- API, данные, состояние, отправка, вложения, голосовые, треды, ответы,
  пересылки и статусы — общие, без дублирования;
- добавление третьей темы не должно требовать переработки.

## Решение

Три слоя, по одному на каждый вид различий.

### 1. Логика — одна на все оформления

`useChatAppState` уже собирает всё: серверные данные (`useChatData`),
UI-состояние (`useChatUiState`), звонки и обработчики. Он вызывается **один
раз** в `ui/ChatApp.tsx` и целиком передаётся оболочке оформления
(`IChatShellProps.state`, `ui/themes/types.ts`). Оформление не владеет данными и
не может завести собственный запрос.

`ChatApp` стал диспетчером на 77 строк: считает состояние, ставит на `<html>`
атрибут выбранного оформления, рендерит оболочку и общие модалки.

### 2. Цвет и форма — переопределение токенов

Весь чат уже был построен на токенах `--th-*` (`app/styles/theme.css`). Новое
оформление — это набор их значений в
`ui/themes/modern/modern.css` под `:root[data-chat-theme="modern"]` (и
`:root.dark[data-chat-theme="modern"]` для тёмного режима).

Атрибут ставится на `<html>`, а не на корень окна, потому что меню действий,
палитра реакций и просмотр вложений рендерятся порталами в `body`.

Переопределяются только токены, которыми пользуется чат. Палитра приложения
(`--th-accent-*`) не трогается: её задаёт общая тема системы.

Чтобы это заработало, потребовались две правки токенов (обе поведенчески
нейтральны, значения по умолчанию совпадают с прежними):

- `--th-action-bg` — заливка круглого основного действия (отправить, «вниз»,
  экран звонка). Раньше её брали у своего пузыря; у оформления с пастельным
  пузырём действие переставало быть акцентным.
- `--th-bubble-out-on-rgb` — цвет содержимого своего пузыря. Раньше вложения и
  голосовые внутри пузыря красились через `--th-on-accent-*`; на светлом пузыре
  белый текст не читался.

### 3. Структура — оболочка на оформление

```
ui/
  ChatApp.tsx                 диспетчер: состояние → оболочка
  ChatOverlays.tsx            модалки, общие для всех оформлений
  components/
    ConversationFeed.tsx      лента и всё вокруг неё — общая обвязка
    ChatThemeMenu.tsx         переключатель оформления
    MessageMeta.tsx           время и статус: внутри пузыря или под ним
  themes/
    types.ts                  IChatShellProps — контракт оболочки
    classic/                  текущий дизайн (перенос из ChatApp)
    modern/                   новый дизайн + modern.css
```

Различия, которые не выражаются токенами и нужны глубоко в ленте, описаны
данными в `model/chatThemes.ts` (`IChatThemePresentation`): где стоит время и
статус сообщения и есть ли аватарка рядом с пузырём. `ChatMessageItem` читает их
хуком `useChatThemePresentation()` — прокидывать флаг через `MessageList` и
`DateGroupSection` не потребовалось.

### Хранение выбора

`lib/chatThemeStore.ts` — хранилище вне React на `useSyncExternalStore`.
Раздел «Чат» и всплывающее окно — два независимых поддерева без общего
провайдера, а оформление у них одно. Выбор пишется в `localStorage`
(`chat:theme`) и переживает перезагрузку.

### Где переключатель

Рядом с переключателем края панели бесед: обе настройки про вид окна, и искать
их логично в одном месте. В классическом оформлении — в блоке управления
(`ChatHeader`), в современном — в карточке управления панелью
(`ModernPanelControls`). Компонент один, меняется только тон кнопки.

## Соответствие макетам

- панель бесед слева / справа — карточка управления над карточкой списка;
- панель сверху / снизу — карточка управления слева от полосы аватарок;
- беседа — три карточки: шапка, лента, поле ввода.

Кнопки-пилюли в шапке сопоставлены с существующими возможностями, новых ручек
под них не заводилось:

| Пилюля | Действие |
|---|---|
| PIN | показать плашку закреплённого; повторное нажатие — переход к сообщению |
| Ветка | открыть последнее обсуждение беседы (списка тредов в системе нет) |
| + | новая беседа (`ComposeModal`), скрыта без права `chat.create` |

## Как добавить третье оформление

1. Запись в `CHAT_THEMES` (`model/chatThemes.ts`) + подписи в `lib/translations.ts`.
2. Блок токенов под `:root[data-chat-theme="<id>"]` в CSS оформления.
3. Оболочка с пропсами `IChatShellProps` и строка в `SHELLS` (`ui/ChatApp.tsx`).

Ни данные, ни обработчики при этом не трогаются.

## Верификация

Сборка, проверка типов и браузерная проверка не запускались — по правилам
`AGENTS.md` §18 их выполняет пользователь. Что проверить в браузере:

- переключение оформления в разделе и во всплывающем окне, сохранение после F5;
- все четыре положения панели бесед в обоих оформлениях;
- светлый и тёмный режим;
- отправка текста, вложений и голосового; ответ, пересылка, реакции, тред,
  закрепление, удаление; поиск по сообщениям; догрузка старых сообщений.
